# Simplex Invoices and Quotes

Internal Simplex Sciences app for invoices and quotes. 

**Invoices.** Reads POs as PDFs, especially Thermo Fisher, and produces the Word invoice after staff reviews each field. POs and order letters from other customers are read by their labels (PO number, Bill To, Ship To, and the item table).

**Quotes.** Builds a Word quote in the same layout as the quotes we send (for example `2025_10_28_MERCK.docx`). Products and list prices are up to date for 2026. The FedEx shipping price is still entered by hand.
